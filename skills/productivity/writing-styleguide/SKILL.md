# Documentation writing style

Apply the user's preferred style to documentation and user-facing prose without changing the intended meaning.

## Style rules

- Use sentence case for headings, titles, labels, and list text.
- Write responses in sentence case rather than title case.
- Preserve proper nouns, branded terms, and required identifiers exactly.
- Follow explicit project conventions and the established style of nearby documents when they differ from the default.
- Make focused edits; do not rewrite unrelated content.
